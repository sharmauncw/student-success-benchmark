# Data dictionary — Student Success & Value Benchmark

> **Everything in `data/` is synthetic demo data.** The numbers are fictional and
> were generated by `data/generate_data.py`. They are shaped to look like the
> kind of first-year retention and graduation-rate reporting an
> institutional-research office produces, but they do **not** come from any real
> institution and must not be treated as real.

Regenerate everything from scratch:

```bash
python data/generate_data.py
```

## Grain

`fact_student_outcomes.csv` — one row per unique combination of
**cohort year × residency × student type × Pell status × race/ethnicity**
(8 cohort years × 2 × 2 × 2 × 7 = 448 rows).

## Tables

### `dim_cohort.csv`
| column | description |
|---|---|
| `cohort_year` | Entering fall cohort year (2017–2024) |
| `cohort_label` | Display label, e.g. "Fall 2024" |
| `cohort_size` | Entering headcount for the cohort |

### `dim_residency.csv`
`residency_key` (`IN`, `OUT`) → `residency` ("In-State", "Out-of-State")

### `dim_student_type.csv`
`student_type_key` (`FT`, `TR`) → `student_type` ("First-Time", "Transfer")

### `dim_pell_status.csv`
`pell_key` (`P`, `N`) → `pell_status` ("Pell Recipient", "Non-Pell")

### `dim_race_ethnicity.csv`
`race_key` → `race_ethnicity` ("White", "Hispanic/Latino",
"Black or African American", "Asian", "Two or More Races",
"Nonresident Alien", "Unknown")

### `fact_student_outcomes.csv`
| column | description |
|---|---|
| `cohort_year` | FK → `dim_cohort` |
| `residency_key` | FK → `dim_residency` |
| `student_type_key` | FK → `dim_student_type` |
| `pell_key` | FK → `dim_pell_status` |
| `race_key` | FK → `dim_race_ethnicity` |
| `cohort_n` | Students in this cell |
| `retained_1yr_n` | Of `cohort_n`, still enrolled one fall later |
| `grad_4yr_n` | Graduated within 4 years; **NULL for cohorts 2022+** (not yet observable) |
| `grad_6yr_n` | Graduated within 6 years; **NULL for cohorts 2020+** (not yet observable) |
| `avg_debt_usd` | Average cumulative debt at exit for the cell, USD |

### `peer_benchmark.csv`
Fictional "system average"-style benchmark rates per cohort year, for the
vs-benchmark deltas on the dashboard. Columns: `cohort_year`,
`benchmark_retention`, `benchmark_grad_4yr`, `benchmark_grad_6yr`,
`benchmark_debt`. (NULLs mirror the same observability windows as the fact.)

### `peer_institutions.csv`
Fictional College-Scorecard-style peer set for the scatter visual.
Columns: `institution`, `completion_rate` (%, 150% of normal time),
`avg_net_price` (USD), `is_demo` (TRUE only for "Demo University").
